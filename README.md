# 🧠 Cognitive Knowledge Engine & Analytics Dashboard

A professional, full-stack AI Knowledge Retrieval and Analytics system built using **Python Flask** and **RESTful API integration**. Designed for academic presentation and real-time information processing.

## 🚀 Features
- **Advanced Search Hub:** Real-time information querying with responsive cards and external reference links.
- **Analytics Dashboard:** Live telemetry metrics tracking total queries, success rates, and gateway statuses.
- **Session Audit Logs:** Interactive data tables recording execution timestamps and query states.
- **Modern Dark UI:** Clean, custom-designed CSS design system matching professional SaaS dashboards.

## 🛠️ Technology Stack
- **Backend:** Python, Flask Framework
- **Frontend:** HTML5, CSS3 Grid/Flexbox Layouts
- **Data Source:** Wikipedia Cloud REST API Endpoints
